# TalentDesk

TalentDesk is a multi-company Human Resource Management System (HRMS) currently under development.

The goal is to build a centralized platform for managing company information, users, and recruitment workflows for multiple organizations.

## Tech Stack

**Frontend:** React, Vite, JavaScript

**Backend:** Python, FastAPI, SQLAlchemy

**Database:** PostgreSQL (Supabase)

**Database Migrations:** Alembic

**Dependency Management:** Poetry

## Current Progress

- Company management
- User management
- Company-specific role assignments
- Database schema and migration setup
- Frontend and backend integration

## Planned Features

- User authentication and authorization
- Company-scoped access control
- Job and recruitment management
- Candidate application tracking
- Interview scheduling and management

## Project Status

**In active development.**

Features and architecture may change as development progresses.

## Security

Credentials, API keys, database connection strings, and other sensitive configuration must be stored securely in environment variables and excluded from version control.
