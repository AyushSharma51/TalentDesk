Phase 2 TalentDesk development roadmap

1. Applicants Management
   - Display applicants by company and job.
   - View candidate profiles.
   - Preview/download resumes.
   - Update application status.

2. Public Careers APIs
   - Public endpoint to fetch published jobs.
   - Application submission without login.
   - PDF resume upload to Supabase Storage.
   - Save applicant details in PostgreSQL.

3. Sofsure Careers website
   Separate public-facing website connected to TalentDesk.

4. NBMC Careers website
   Separate public-facing website using the same backend.

5. Interviews Management
   - Schedule interviews.
   - Assign interviewers.
   - Record feedback and ratings.
   - Track interview rounds.

6. Dashboard improvements
   - Applicant statistics.
   - Job performance.
   - Hiring pipeline.
   - Company-specific analytics.

7. Production deployment
   - Deploy backend and frontends.
   - Configure domains and HTTPS.
   - Secure file uploads.
   - Configure live dashboard updates.
